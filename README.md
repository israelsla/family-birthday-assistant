# Family Birthday Assistant

מערכת Web לניהול ימי הולדת עבריים, בעברית ו-RTL. תומכת בכמה משפחות
בו-זמנית (כל משפחה מבודדת לגמרי מהאחרות), עם:

- שמירת בני משפחה עם תאריך לידה **עברי** (יום/חודש/שנה) ב-SQLite, מוצג באותיות עבריות.
- דשבורד עם באנר בולט "מי חוגג היום", ימי הולדת קרובים, ימי נישואין, ואירועים משפחתיים חופשיים.
- עמוד "כל בני המשפחה" עם הוספה/עריכה/השבתה, וניהול זוגות.
- התחברות (חשבון אחד משותף לכל בני משפחה אחת).

**"מי חוגג היום" מוצג רק כשמישהו נכנס לדשבורד** — אין שליחה אוטומטית לשום ערוץ חיצוני (לא WhatsApp, לא מייל), ואין שום תהליך שרץ ברקע.

## מבנה הפרויקט

```
app/
├── __init__.py          # יצירת אפליקציית Flask (application factory)
├── auth.py              # התחברות/התנתקות (הרשמה עצמאית סגורה - ראו למטה)
├── db.py                # חיבור ל-SQLite ואתחול הסכמה
├── models.py            # כל שאילתות ה-SQL, מסוננות לפי family_id
├── routes.py            # ה-routes של האתר (דורשים התחברות)
├── hebrew_numerals.py   # המרות בין מספרים לאותיות עבריות (יום/שנה)
├── hebrew_calendar.py   # חישובי לוח עברי (מתי הבא, גיל)
├── templates/           # תבניות HTML (Jinja)
└── static/              # CSS ו-JS
schema.sql               # families, users, family_members, marriages, family_events
run.py                   # הרצת שרת האתר
tools/                   # סקריפטים חד-פעמיים/ניהוליים (ראו למטה)
```

## התקנה והרצה מקומית

```bash
cd BirthdayProject
python3 -m venv venv
source venv/bin/activate          # ב-Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```

לאחר מכן פותחים דפדפן בכתובת: http://127.0.0.1:5000

מסד הנתונים (`instance/family.db`) נוצר אוטומטית בהרצה הראשונה, לפי `schema.sql`.

## משתני סביבה

הקובץ `.env` (שנוצר מ-`.env.example`) מחזיק ערכים שלא נכנסים ל-Git:

- `SECRET_KEY` — מפתח סודי של Flask (מאבטח את ה-session/ההתחברות). **בפריסה אמיתית באינטרנט חובה ערך אקראי אמיתי, לא ברירת המחדל.**
- `DATABASE_PATH` — נתיב לקובץ ה-SQLite.

## יצירת משפחה חדשה (הרשמה עצמאית סגורה)

אין כרגע דף הרשמה פתוח לציבור. כדי ליצור משפחה חדשה (כולל הראשונה, בהתקנה חדשה):

```bash
python tools/create_family.py
```

ישאל אינטראקטיבית שם משפחה, אימייל וסיסמה, וייצור התחברות חדשה עם אותם פרטים.

## כלים נוספים ב-`tools/`

- `build_import_csv.py` / `import_to_db.py` — ייבוא חד-פעמי מקובץ PDF/CSV של רשימת ימי הולדת (ספציפי לפרויקט המקורי).
- `seed_marriages.py` — קישור זוגות ידוע מראש.
- `migrate_to_multitenant.py` — המרה חד-פעמית של מסד נתונים ישן (משפחה יחידה) למבנה הרב-משפחתי.
